## ¿Qué es UniGO?

UniGO es una aplicación de carpooling diseñada específicamente para estudiantes universitarios en España. Permite a los estudiantes compartir viajes entre universidades, residencias y otros destinos comunes, ahorrando dinero y contribuyendo al medio ambiente.

## Cómo funcionan los viajes

1. **Publicar un viaje (Conductor):**
   - El conductor publica un viaje indicando: origen, destino, fecha, hora, plazas disponibles, precio por plaza, y detalles del vehículo
   - El viaje queda visible en el buscador para otros usuarios
   - El conductor debe tener configurada su cuenta bancaria (IBAN) para recibir pagos

2. **Buscar y reservar (Pasajero):**
   - Los pasajeros buscan viajes por origen, destino y fecha
   - Pueden solicitar una plaza haciendo una reserva
   - La reserva queda en estado PENDING hasta que el conductor la acepte
   - El pasajero debe tener una tarjeta de pago guardada

3. **Aceptar/Rechazar reservas:**
   - El conductor recibe notificaciones web y por email de nuevas solicitudes
   - Puede aceptar o rechazar cada solicitud
   - Al aceptar, la reserva pasa a CONFIRMED y se retiene el pago

## Cómo funcionan las alertas automáticas

1. **Crear alerta:**
   - Los pasajeros pueden crear alertas de búsqueda automática
   - Especifican: origen, destino, hora objetivo, días de la semana o fechas específicas, y flexibilidad horaria

2. **Funcionamiento:**
   - El sistema busca automáticamente viajes compatibles (nuevos y existentes)
   - Cuando encuentra uno, crea una reserva PENDING automáticamente
   - El pasajero recibe una notificación
   - Si el conductor rechaza, la alerta sigue activa y busca otro conductor
   - El sistema evita bucles infinitos: cada conductor solo se intenta una vez por alerta

3. **Cancelar alerta:**
   - Al cancelar una alerta, se cancelan todas las reservas pendientes asociadas

## Cómo funciona el sistema de pagos (Stripe)

1. **Guardar tarjeta:**
   - Los pasajeros deben guardar al menos una tarjeta en "Mis Tarjetas"
   - Se usa Stripe SetupIntent (no se cobra al guardar)
   - La tarjeta se guarda para uso futuro

2. **Reservar viaje:**
   - Al crear una reserva (PENDING), NO se cobra nada
   - Cuando el conductor acepta, se crea un PaymentIntent con captura manual
   - El pago se retiene pero NO se cobra todavía

3. **Completar viaje:**
   - Cuando el viaje se completa, el PaymentIntent se captura
   - Se aplica una comisión del 15% para la plataforma
   - El 85% restante se transfiere al conductor vía Stripe Connect

4. **Penalizaciones por cancelación:**
   - Si el pasajero cancela >24h antes: 0% de penalización
   - 12-24h antes: 30%
   - 6-12h antes: 50%
   - ≤6h antes: 80%

## Cómo funciona Stripe Connect (IBAN del conductor)

1. **Configurar IBAN:**
   - Los conductores deben añadir su IBAN en "Mis Tarjetas" → sección "Cuenta Bancaria"
   - Completan un formulario con: nombre, apellidos, fecha de nacimiento, DNI/NIE, dirección, e IBAN
   - Esto crea una cuenta Stripe Connect Custom

2. **Recibir pagos:**
   - Cuando un viaje se completa, se crea un Transfer automáticamente
   - Stripe envía el dinero (85% del precio) al IBAN del conductor
   - El payout es automático, el conductor no necesita hacer nada

3. **Validaciones:**
   - No se puede publicar un viaje sin tener IBAN configurado
   - La plataforma retiene 15% de comisión por cada viaje completado

## Gestión de tarjetas e IBAN

**Mis Tarjetas** tiene dos secciones:

1. **Tarjetas de Pago (Pasajeros):**
   - Para reservar viajes
   - Se pueden añadir, ver y eliminar tarjetas
   - Al menos una tarjeta es necesaria para reservar

2. **Cuenta Bancaria - IBAN (Conductores):**
   - Para recibir pagos de viajes completados
   - Se puede añadir, editar y eliminar el IBAN
   - Usa Google Places Autocomplete para la dirección
   - Obligatorio para publicar viajes

## Características adicionales

- **Chat del viaje:** Los pasajeros confirmados y el conductor pueden chatear
- **Valoraciones:** Después de cada viaje, conductor y pasajero se valoran mutuamente
- **Historial:** Todos los viajes (como conductor o pasajero) se guardan en "Registro"
- **Notificaciones:** Web y por email para reservas, aceptaciones, rechazos, etc.
- **Viajes favoritos:** Guardar plantillas de viajes frecuentes
